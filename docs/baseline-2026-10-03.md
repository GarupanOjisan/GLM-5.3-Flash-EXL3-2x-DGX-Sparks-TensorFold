The v1.5 baseline is in `baseline-2026-10-04-v1.5.md`.

Measured on the live two-Spark server (v1.3-era image, see the correction above).

- Endpoint: `192.168.4.165:8000`, model id `spark-model` (not the recipe's default `GLM-5.3-Flash-EXL3`)

- Per-request tok/s = (tokens - 1) / (last token - first token). Aggregate = all tokens / (first token of any request to last token of any).
